# Telegram-бот для онлайн-записи

Это бот для записи на приём: админ настраивает расписание, клиенты сами выбирают свободный день и время кнопками прямо в Telegram. Подойдёт для небольших сервисов: мастера, репетитора, консультанта.

## Возможности

**Для клиента**
- выбор дня из ближайших рабочих дней;
- выбор времени из свободных слотов: занятые и прошедшие слоты не показываются;
- ввод имени и email, подтверждение записи.

**Для администратора**
- `/schedule`: настройка рабочих дней недели, времени начала и конца приёма, интервала между записями (в минутах);
- `/start`: просмотр списка всех записей;
- мгновенное уведомление в Telegram о каждой новой записи.

**Надёжность**
- слот перепроверяется дважды (при выборе времени и перед сохранением), чтобы не записать двух человек на одно время;
- валидация ввода: формат времени `HH:MM`, положительный интервал, проверка email;
- все SQL-запросы параметризованы, а команды администратора доступны только по его Telegram ID.

## Технологии

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/): FSM, инлайн-клавиатуры, фильтры
- aiosqlite: асинхронная работа с SQLite
- python-dotenv: конфигурация через переменные окружения

## Запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/MistorX/telegram-booking-bot.git
   cd telegram-booking-bot
   ```

2. Установите зависимости:
   ```bash
   pip install aiogram aiosqlite python-dotenv
   ```

3. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен. Свой Telegram ID можно узнать, например, у `@userinfobot`.

4. Создайте файл `.env` рядом с `tg_bot_manager.py`:
   ```env
   TOKEN=токен_бота
   ADMIN_ID=ваш_telegram_id
   ```

5. Запустите бота:
   ```bash
   python tg_bot_manager.py
   ```

6. Откройте бота в Telegram, отправьте `/schedule` и настройте расписание. После этого клиенты смогут записываться через `/start`.

> Файл `.env` и база `ww.db` содержат секреты и персональные данные, поэтому не добавляйте их в репозиторий (внесите в `.gitignore`).

## Как пользоваться

| Команда / кнопка | Кто | Что делает |
|---|---|---|
| `/start` | клиент | начинает запись: день → время → имя → email |
| `новая запись` | клиент | то же, что `/start` (кнопка после записи) |
| `/start` | админ | показывает список всех записей |
| `/schedule` | админ | настройка расписания приёма |

## Структура данных

База SQLite `ww.db` создаётся автоматически при первом запуске.

**`zapis`**: записи клиентов

| поле | тип | описание |
|---|---|---|
| name | TEXT | имя клиента |
| email | TEXT | email клиента |
| date | TEXT | дата, `YYYY-MM-DD` |
| time | TEXT | время, `HH:MM` |
| chat_id | TEXT | чат клиента в Telegram |

**`schedule`**: расписание (одна строка = один рабочий день недели)

| поле | тип | описание |
|---|---|---|
| weekday | INTEGER | день недели, 0 = Пн … 6 = Вс |
| start_time | TEXT | начало приёма, `HH:MM` |
| end_time | TEXT | конец приёма, `HH:MM` |
| interval_min | INTEGER | шаг между записями, минуты |
